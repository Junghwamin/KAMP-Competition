## area  (01:43.7 ~ 02:48.9)

- **[01:43.7]** PR-AUC는 이 곡선 아래 넓이입니다. 우리 코드는 점 사이를 비스듬히 잇지 않고 계단으로 넓이를 잽니다. 이 값을 평균 정밀도, AP라고 부릅니다.  <sub>(11.9s)</sub>
  - 화면: 왼쪽 위 수식 AP = Σ (R_n − R_{n−1}) · P_n, 오른쪽 PR 평면에 계단 아래 면 칠하기
- **[01:55.6]** 넓이는 Recall이 늘어나는 칸에서만 생깁니다. 폭은 3분의 1씩 세 칸, 높이는 그 순간의 Precision인 1, 3분의 2, 0.5입니다.  <sub>(11.7s)</sub>
  - 화면: 직사각형 세 개에 폭·높이 라벨
- **[02:07.3]** 더하면 0.722. 피크를 하나 찾을 때마다 그 순간의 Precision을 적어 두었다가 평균 낸 값과 같습니다.  <sub>(9.3s)</sub>
  - 화면: 검산 스택: 1/3×1 + 1/3×0.667 + 1/3×0.5 = 0.722
- **[02:16.6]** 그런데 0.722는 좋은 값일까요? 여섯 시간 중 세 시간이 피크라서, 무작위로 경보를 울려도 Precision은 평균 0.5입니다.  <sub>(11.7s)</sub>
  - 화면: PR 평면에 높이 0.5 수평선
- **[02:28.3]** 이 높이를 무기술선이라 부르고, 값은 양성률과 같습니다. 그래서 AP를 양성률로 나눈 lift, 여기서는 1.44배를 함께 봅니다.  <sub>(11.4s)</sub>
  - 화면: 무기술선 라벨 + lift = 0.722 / 0.5 = 1.44
- **[02:39.7]** 하나 더, AP는 점수의 순서만 씁니다. 킬로와트 예측값이든 확률이든 같은 잣대로 비교할 수 있다는 뜻입니다.  <sub>(9.2s)</sub>
  - 화면: 두 칩: kW 점수 / 확률 점수 → 같은 줄 세우기 → AP
