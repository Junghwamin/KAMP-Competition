# _original — 보관 전 원본 (수정 금지)

바탕화면에서 실행할 때의 **손대지 않은** 계획서와 주 스크립트다. 상위 폴더의 같은 파일은 저장소로 옮기며 경로(저장소 기준·`_work/`)와 보관 메모만 바꿨다. 판정 논리는 같다.

원본은 바탕화면 폴더 구조(`KAMP-Competition` 사본을 형제로 둠)를 가정하므로 이 위치에서는 그대로 실행되지 않는다.

⚠️ **경로를 고쳐서 실행하지 말 것.** 원본은 저장소 폴더로 chdir 한 뒤 파이프라인을 import 하므로, 경로만 맞추면 저장소 `outputs/` 의 표와 그림 색인을 덮어쓴다. 다시 돌리려면 상위 폴더의 스크립트를 쓴다.
