# 1단계 분류기 휴무 오분류 수정안 비교 — 계획서

작성 2026-09-25. 대상은 최종모델 **2단계 레짐(3분류)** 이다. **제출물(노트북·보고서·제출 예측)은 바꾸지 않는다.**
목적은 서비스(운영 예측)에 넣을 수정안을 검증해서 나중에 제시할 근거를 만드는 것이다.

## 1. 문제 (이미 측정된 사실)

- 하계휴가 중 평일인 8/2(월)·8/3(화)은 계획 생산량이 0 이다. 그런데 1단계 분류기가 08~17시를 모두 '가동'(레짐 2)으로 보냈다.
  - 실측 21 kW 에 대해 예측은 약 175 kW 였다.
  - 교차검증(OOF) 1,279시간 중 48시간이 OOF MAE 11.007 의 34%(3.76 kW)를 차지한다.
  - 근거: 제출 노트북 6.6절 `ch2_gate_diagnosis.csv`.
- 서비스 위험: 추석(9/20~22, 월~수)이 같은 유형(평일 계획 휴무)이다.

## 2. 수정안 (결과를 보기 전에 고정)

| ID | 수정안 | 무엇을 바꾸나 | 재학습 |
|---|---|---|---|
| A | 현행 (기준) | — | — |
| **R** | **계획 휴무 강제** | 대상일 계획상 휴무(`is_shutdown` = 1, 일생산량 0)인 행은 게이트 출력과 관계없이 **기저 레짐(0)** 회귀모델로 예측한다 | 없음 (예측 단계 후처리) |
| **G** | **게이트 입력 제한** | 1단계 분류기 입력을 **달력·공정상태·생산계획 22개**(시간정보 10 + 공정상태 8 + 생산정보 4)로 줄인다. 과거 전력(지연·이동통계)과 기상은 게이트에서 뺀다. 2단계 회귀는 44개 그대로 | 게이트만 |
| RG | R + G | 둘 다 적용 | 게이트만 |

- 학습 데이터·하이퍼파라미터·레짐 경계(30·70 kW)·2단계 회귀는 모두 현행과 같다.
- R 은 휴무일이 아닌 날의 예측을 **한 개도 바꾸지 않는다**(구조상). G·RG 는 게이트를 다시 학습하므로 모든 날이 바뀔 수 있다.

## 3. 평가 — 교차검증(OOF)만으로 판정, 테스트는 판정에 쓰지 않는다

- fold 2~5 (D1), 최종모델과 같은 코드·설정(FULL, 트리 800·게이트 400).
- 기준 A 는 커밋된 결과(OOF MAE 11.0067)를 재현해야 한다. 재현되지 않으면 멈춘다.
- **잡음 폭**은 제출 노트북 6.6절 값을 그대로 쓴다: MAE 0.200 kW, Peak-MAE 0.962 kW.

**서비스 적용 후보 기준** — 아래를 **모두** 만족해야 한다.

| 기준 | 내용 | 왜 |
|---|---|---|
| ① | OOF MAE 개선의 일 단위 블록 부트스트랩 95% CI 가 0 을 포함하지 않는다 | 실제로 좋아지는가 |
| ② | 휴가가 없는 fold 2·5 각각에서 악화 ≤ 잡음 폭 | 정상 운영을 해치지 않는가 |
| ③ | 정상일(대상일과 7일 전의 가동 상태가 같은 날)에서 악화 ≤ 잡음 폭 | 〃 |
| ④ | Recall 하락 ≤ 0.01, Peak-MAE 악화 ≤ Peak-MAE 잡음 폭 | 피크 탐지를 해치지 않는가 |
| ⑤ | **문제의 이틀(8/2·8/3)을 뺀 OOF MAE 의 악화 ≤ 잡음 폭** | 고친 곳 말고 다른 곳을 망치지 않는가 (가장 중요) |
| ⑥ | 복제 제거 조건 D2 에서도 OOF MAE 가 개선된다 | 증강 복제 데이터에 기댄 결과가 아닌가 |

- 여럿이 통과하면 **단순한 것**을 고른다: R(재학습 없음) > G > RG.
- 단, 복잡한 쪽이 ⑤의 값(이틀 제외 MAE)을 잡음 폭보다 더 개선하면 그쪽을 고른다.
- ①은 이틀을 고치기만 하면 거의 자동으로 통과한다. 그래서 판정의 실질은 ②③④⑤⑥ 이다.
  이 이틀은 문제를 발견한 바로 그 데이터이므로, **OOF 개선 폭 자체를 성과로 내세우지 않는다.**

## 4. 판정 뒤 보고만 하는 것 (선택에 쓰지 않음)

1. **테스트(9/1~9/14) 영향**
   - 각 수정안의 테스트 MAE 와 피크 탐지 결과를 본다. τ 는 각자의 OOF 에서 같은 규칙(fold τ 중앙값)으로 정한다.
   - 테스트 기간에는 평일 휴무가 없으므로 변화가 작을 것으로 예상한다.
2. **평일 계획 휴무 가정 시나리오** (추석 대리 실험)
   - 9/1~9/14 의 평일 10일 각각에 대해 "그날 계획 생산량 0(휴무)"이라고 가정한다.
   - 9/1 이전 데이터로 학습한 모델이 그날을 얼마로 예측하는지 본다.
   - 실측이 없는 가정이다. 참고값은 실제 휴가 중 평일(8/2·8/3)의 실측 약 21.5 kW 이다.
3. **서빙 시제품**
   - 채택안이 R 이면 기존 평가 번들을 그대로 쓰고 예측 단계에만 보정을 거는 서빙 옵션을 만든다.
   - 2의 가정 시나리오를 실제 서빙 경로(`serving` 패키지)로 다시 돌려, 실험 결과와 같은지 교차 확인한다.
